# Design Constitution — Universal Standing Law (all projects)
> Synced 2026-06-09 from the workspace `design-constitution.md` (10-rule summary via
> DESIGN-SYNC.md). Applies to EVERY project in this workspace, not just Ananda Taskboard.
> Project-specific rules live in `CLAUDE.md` + `DESIGN-DECISIONS-LOG.md`.

1. **ASSET INTEGRITY** — never generate/recreate/approximate a logo, wordmark, or identity
   asset; no AI-invented or artifacted marks EVER; missing asset = ask, or a clearly-labeled
   gray placeholder.
2. **Connected controls perfectly aligned** — side-by-side = flush both edges; groups align
   as a unit. (Taskboard: D39.)
3. **Text never hard-clips** — ellipsis + reachable full text (tooltip/expand) / "+N"
   overflow / wrap. (Taskboard: D42.)
4. **ONE spacing token per app** between sibling form rows. (Taskboard: D35 `--gap-form`.)
5. **Line-art icons; emoji never as chrome** — project allowlist exceptions only.
   (Taskboard: D34; allowlist = project-picker emoji.)
6. **Real fonts actually loaded; no faux-bold; anti-slop font bans.**
7. **Every state designed** — empty / loading / error / first-run / overflow / disabled,
   light + dark, each breakpoint.
8. **WCAG AA floor.**
9. **No purple-gradient / glassmorphism / nested-card slop.**
10. **Honest fidelity** — reproduce existing agreed designs 100% before adding anything new.
    (Taskboard: RULE #0.)
